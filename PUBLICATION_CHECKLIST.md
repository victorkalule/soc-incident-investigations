# Public Release Checklist

Before changing this repository from private to public:

- [ ] Confirm TripleTen and dataset terms allow public summaries and any proposed screenshots.
- [ ] Verify every result and technical assertion against the original training reports.
- [ ] Remove passwords, tokens, sensitive accounts, private logs, personal data, and nonpublic indicators.
- [ ] Use only screenshots that have been redacted and explicitly approved for sharing.
- [ ] Do not upload original training templates or reports marked confidential.
- [ ] Make clear that the exercises used historical/simulated data rather than live company incidents.
- [ ] Consider screenshots that illustrate workflow (redacted queries, timelines, ATT&CK mapping) instead of raw datasets.
